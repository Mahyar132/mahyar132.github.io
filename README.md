# Isotope

Isotope is a personal website by Mahyar (Varen), built as a small space for experimentation, creativity, software, and art.

It is designed to be simple, lightweight, and independent. No complicated infrastructure, no unnecessary frameworks, and no backend requirements.

## About

Isotope is my main website where I share my projects, artwork, experiments, and interests.

It is not intended to be a commercial product or a general-purpose website template. It is an evolving personal project, built and maintained independently.

## Features

- **Static by design:** No server-side application or database required.
- **Lightweight:** Built with HTML, CSS, and vanilla JavaScript.
- **Responsive:** Designed to work across desktop and mobile devices.
- **Minimal dependencies:** Uses only the tools and libraries needed.
- **Self-hostable:** Can be hosted on GitHub Pages or any static web server.
- **Open source:** Source code is available for inspection, modification, and redistribution.
- **Privacy-conscious:** No unnecessary tracking infrastructure or invasive functionality.

## Technologies

Isotope is built using:

- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap

Additional services may be used for specific functionality, such as GoatCounter for website statistics and giscus for comments.

## Project Philosophy

Isotope follows a few simple principles:

- **Simplicity over complexity:** Avoid unnecessary abstractions, dependencies, and infrastructure.
- **Independence:** Prefer static technologies and tools that do not require a particular hosting provider.
- **Freedom:** Keep the source code available and respect software freedom.
- **Transparency:** Make the implementation accessible and understandable.
- **Creativity:** Leave room for experimentation without turning everything into a framework.

The goal is not to build the biggest or most sophisticated website. It is to build something useful, personal, and maintainable.

## Running Locally

Isotope is a static website. You do not need Node.js, Docker, a database, or a build system to run it.

You can simply clone the repository:

```bash
git clone https://github.com/Mahyar132/Mahyar132.github.io.git
```

Then open `index.html` in your browser.

Alternatively, use any local static HTTP server.

## Deployment

The website is hosted using GitHub Pages.

To deploy your own version, fork the repository, configure GitHub Pages for your repository, and publish the static website.

No compilation or server-side deployment process is required.
